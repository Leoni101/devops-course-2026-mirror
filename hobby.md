# Мой пет-проект
Идея:сайт-визитка музыкальной школы — с описанием курсов, расписанием занятий, фотографиями классов и формой записи на пробный урок.
Стек: HTML, CSS, JavaScript. Возможно, лёгкий фреймворк (Vue или React) для интерактивных форм. Хостинг — GitHub Pages.
Цель: научиться верстать адаптивные страницы, работать с формами и деплоить статические сайты через GitHub Pages.
